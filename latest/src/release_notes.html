Release Notes

Every release is published three times from the same text: as an annotated git tag, as a GitHub Release and as a section of the CHANGELOG.md file at the root of the repository.

The manual of each release is kept next to the manual of the current main branch and can be selected from the version menu at the top of the page. The manual you are reading now describes the version selected there.

Highlights

v3.6.1-beta

2026-11-23

!include of a whole configuration file works again, the manual is built for every release and !include is documented.

v3.6.0-beta

2026-11-21

Particle building through one reader per attribute, entry_range access, chunked parallel runs whose parts are merged by ROOT, and a progress bar that refreshes ten times per run.

v3.5.0

2026-05-11

ROOT Draw(...) expressions in histogram definitions, multiprocessing removed from fill-histos, fixes to the events dumper.

dtpr dump-events and dtpr.utils.dumper, lists and glob patterns as input, faster EventList entry access, --cores deprecated.

v3.3.0

2026-02-16

!include directive for YAML configuration files, visualizer canvas fix.

v3.2.0

2026-02-11

Several input NTuples, configuration split across files, keyword arguments forwarded to src, move to the INTREPID-hep organisation.

v3.0.0

2025-09-11

Package restructure, PEP 621 packaging, tests and continuous integration, manual on GitHub Pages, YAML artist configuration, parallel fill-histos, renamed inspect-events and events-visualizer.

method3 classifier and clean-up.

No v3.1.0 was ever tagged. v3.3.0 and v3.4.0 were first tagged v3.3.0-beta and v3.4.0-beta, and the version recorded inside those trees still carries the -beta suffix.
